# Fonctionnalité — AI Builder

Le Builder est **dans** l’app. Pas de gestionnaire de plusieurs applications.

## Parcours (tout public)

1. L’écran, c’est **son appli** (vide au début), en plein écran.
2. Un bouton **U** flottant, semi-transparent, **déplaçable**, ouvre une fenêtre compte Uforge.
3. Après connexion : **conversation**. On décrit, on ajuste, message après message.
4. En conversation, l’écran est **coupé en deux** : aperçu (iframe) au-dessus, feuille Uforge en dessous, **sans recouvrement** — sinon le doigt n’atteint pas l’iframe. Composer + « Tout remettre à zéro » restent visibles (le fil défile). **Utiliser mon appli** compile et **chiffre** le `.happ` sur l’appareil, puis ferme la fenêtre.
5. Sans compile, une **nouvelle visite** retrouve une appli vide (le brouillon ne survit pas sur le device). Seul le `.happ` installe l’appli.
6. Pour modifier plus tard : même bouton → **mot de passe** (l’email est dans l’enveloppe) → déchiffrement + connexion → on continue le fil.

Compile ne termine pas le projet. Une seule `.happ`.

## Accès

Le bouton flottant révèle l’entrée. La sécurité = compte Uforge.
